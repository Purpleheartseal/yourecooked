Privacy policy

Last updated: September 17, 2026

This policy describes the current version of the 3D XO website and game. It includes the A-ADS banner embedded on the game page.

Game data stays in your browser

The game does not ask you to create an account or submit a name, email address, or payment information. Moves, player settings, and scores are held in your browser's memory for the current page session. The application does not send these to a game server or save them in cookies or local storage.

AI moves are calculated locally in a browser worker. Your board is not sent to an external AI service. Reloading or closing the page clears the in-memory game state.

Requests to external services

The game loads the Three.js graphics library and its controls from UNPKG, a public content delivery network. When your browser requests those files, that service and its infrastructure providers receive connection information such as your IP address and browser request headers. Depending on browser policy, a request may also include referrer information. These requests are necessary for this version of the 3D game to load.

The landing page and this policy use locally hosted styles and system fonts; they do not load an external font or analytics library.

Website hosting

The hosting provider receives ordinary web requests when you visit the site. These can include an IP address, requested URL, browser information, and request time. When this site is hosted on GitHub Pages, GitHub processes information under its General Privacy Statement. GitHub states that it logs visitors' IP addresses for security purposes on GitHub Pages.

This application does not control the hosting provider's operational logs or retention practices. If you are viewing a local preview, the local server rather than GitHub serves the website.

Cookies, analytics, and advertising

The game page embeds an advertisement from A-ADS (unit 2455659) in an iframe loaded from acceptable.a-ads.com. Loading the game automatically requests this third-party content. The provider and any services used inside the ad may receive your IP address, browser request headers, and other information associated with those requests. Their processing is governed by their own privacy terms, not by the game's local-only handling of moves and scores.

The game itself does not set cookies or use analytics. This statement does not guarantee that third-party ad content never uses storage or tracking technologies. Google AdSense is not integrated. No consent-management platform is included; the operator must assess the actual ad configuration and any consent requirements before deployment.

The banner's close button removes the iframe for the current page visit. This stops that embedded frame but does not undo requests already sent. Reloading the page loads the banner again. Browser content-blocking settings may prevent the ad request entirely.

Your choices

You can stop using the game and close the page to discard its in-memory state. Browser privacy settings can restrict network requests and clear cached site files, though blocking the graphics library will prevent the game from loading. Requests relating to a hosting provider's own records should use that provider's privacy channels.

Children and personal information

The game has no form for submitting personal information and does not intentionally ask children to provide it. This does not eliminate the hosting and library requests described above. The operator must ensure the advertising setup is appropriate for the actual audience and applicable children's privacy requirements.
